
# AWS From Clicks to Code — Event Microsite Plan

## Purpose

This document is the source of truth for the next phase of the AWS From Clicks to Code event microsite.

The website should function as a cinematic event experience that:
- explains the event clearly;
- answers attendee questions progressively;
- builds excitement around the hands-on workshop;
- establishes trust through speaker, college, organizer, and supporter information;
- makes registration easy at every point in the journey.

The website should not feel like a technical presentation that happens to advertise an event. It should feel like an event microsite that uses cinematic storytelling to help visitors understand the opportunity and register.

---

## Global Registration Requirement

A **Register on Meetup →** CTA must be available throughout the entire website.

### Persistent CTA
Keep a visible **Register on Meetup →** button in the navigation/header while the attendee scrolls.

### Strategic CTAs
Also place larger registration CTAs at natural decision points, including:
- Hero
- Event overview
- Who should attend
- What attendees will learn
- Hands-on lab
- Registration instructions
- What to bring
- Final CTA

Every registration CTA must redirect directly to the official Meetup registration page.

### Registration messaging
Clearly communicate:
- Registration is completely free.
- Only **100 seats** are available.
- Seats are limited, so attendees should register as soon as possible.

# Design Direction

The existing cinematic visual language should be retained where it helps:
- Dark #080b13 base
- Large square grid
- Green #00d26a accent
- Sharp typography
- Strong numbering
- Cinematic transitions
- Clear visual hierarchy
- Responsive layouts

However, content density and visual treatment should adapt to the purpose of each section.

Do not force every section into the same technical/cinematic treatment.

Practical information such as:
- registration instructions;
- check-in;
- requirements;
- FAQ;
- contact information;

should prioritize clarity and scannability over visual complexity.
