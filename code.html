Is this workshop 100% free to attend for students? expand_more

Yes, entirely free of cost! Organized as an educational community initiative by the AWS Student Builder Group MHSSCE to foster cloud excellence and cloud literacy on campus.

Do I need prior AWS or advanced coding experience? expand_more

No prior expertise is needed. The sprint is designed intentionally from Level 100 up to Level 200, starting from the graphical AWS Management Console and gently demystifying how code templates automate those exact steps.

How does Systems Manager connect without Port 22? expand_more

AWS Systems Manager Agent (SSM Agent) communicates outbound over secure HTTPS (Port 443) to AWS management endpoints. It uses an IAM Role policy (AmazonSSMManagedInstanceCore), completely removing the need for open inbound ports or public IP addresses.

Stage Technical Blueprint & Specs

Technical specifications deployed during the live interactive lab:

1. Zero-Trust Security Protocol (AWS Systems Manager): Zero inbound security group rules required. Instances assume IAM Instance Profile with AmazonSSMManagedInstanceCore. Complete session auditing is fed directly to AWS CloudTrail.
2. CloudFormation IaC Stack Engine: Declarative templates executed via AWS CLI, AWS Console, or SAM. Automatic rollback triggers prevent stranded orphaned compute instances if configuration checks fail.
