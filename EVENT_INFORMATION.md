## 7. Workshop Content

The event is a practical cloud journey covering:

1. **Cloud Computing + AWS fundamentals**
2. **Amazon EC2** — provisioning a cloud server
3. **AWS Systems Manager / Session Manager** — secure server access without exposing SSH
4. **Web server** — hosting a customized web page
5. **AWS CloudFormation / Infrastructure as Code** — defining and automating infrastructure

### Learning emphasis

- Practical, hands-on learning
- Build on real AWS infrastructure through the provided AWS Academy Learner Lab
- Move from cloud fundamentals to a working web server and Infrastructure as Code
- Beginner-friendly; curiosity matters more than prior AWS experience
